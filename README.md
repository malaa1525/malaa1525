### Mohamed Alaa Tawfik

Mathematician working in arithmetic geometry and computational number theory
(PhD, King's College London): rational points, Brauer–Manin obstructions and
explicit descent on curves and surfaces.

Here I implement number-theoretic and elliptic-curve algorithms in Rust and C++
as I move toward cryptographic engineering. Each repository says what is tested
and what is still in progress.

**Selected repositories**
- **Montgomery-Multiplication** (Rust): Montgomery modular multiplication with a
  correctness argument, tested against direct 128-bit arithmetic on random
  inputs and edge cases, with CI on every push.
- **EllipticCurveFiniteFieldExplorer** (C++): counts the points of
  y² = x³ + ax + b over F_p using Euler's criterion, checked against an
  independent computation.
- **Square-and-multiply** and **Extended-GCD** (Rust): small building blocks
  for modular arithmetic.
